# Оно тебе надо

Страница аукциона вещей, в которые никто не верил. Проектная работа второго
спринта «Вёрстка. Семантика и лейаут» курса Яндекс Практикума.

Репозиторий: https://github.com/fllflfldldld/ono-tebe-nado-ad.git

## Запуск

Откройте `index.html` в браузере — установка зависимостей и сборка не нужны.
Для локального HTTP-сервера из папки проекта можно выполнить:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Реализация

- Семантическая разметка: шапка, три секции основного содержимого и подвал.
- Grid для шапки, блока об аукционе и подвала; Flexbox для меню и карточек.
- Общие стили адреса и переиспользуемый затемняющий оверлей.
- Локальные шрифты Raleway в форматах WOFF2 и WOFF.
- Относительные пути к ресурсам, якорные ссылки, ссылки на телефон и почту.
- Фиксированный макет шириной 1100 пикселей, согласно заданию.
